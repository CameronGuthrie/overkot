# Widget sizing

Hold **Shift** while the overlay is focused, then drag a panel’s lower-right
corner to change its width and height. Grid resizing follows the same 24 px
alignment grid used to arrange panels. Hold **Alt** while dragging for 1 px
precision, or choose **Precise** as the normal corner-resizing mode in Settings.

In **Settings → Widgets → Widget sizes**, select a widget and enter exact width
and height values. The fields use 1 px steps regardless of the drag preference.
**Default width** restores the panel’s original width; **Fit content** lets its
height follow the content again. Map and data views use **Default height** because
they fill their viewport. Fixed-height panels keep their content scrollable.

**Reset this widget** removes only that panel’s size choices. The existing
**Reset Widget Sizes** control resets all panels. Size choices also apply to
closed panels when they next open and are included in saved layouts.
